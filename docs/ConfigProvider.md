# ConfigProvider

The `ConfigProvider` class is responsible for registering the event middleware components with Laminas/Mezzio applications. It provides dependency injection configuration and command bus pipeline registration.

## Class Definition

```php
<?php

declare(strict_types=1);

namespace Webware\CommandBus\Event;

use Webware\CommandBus\ConfigProvider as BusProvider;
use Webware\Event\Container\EventDispatcherAwareDelegator;

final class ConfigProvider
{
    /**
     * @return array<string, mixed>
     */
    public function __invoke(): array
    {
        return [
            'dependencies'     => $this->getDependencies(),
            BusProvider::class => [
                BusProvider::MIDDLEWARE_PIPELINE_KEY => $this->getPipeline(),
            ],
        ];
    }

    /**
     * @return array<string, mixed>
     */
    public function getDependencies(): array
    {
        return [
            'delegators' => [
                Middleware\PreHandleMiddleware::class  => [
                    EventDispatcherAwareDelegator::class,
                ],
                Middleware\PostHandleMiddleware::class => [
                    EventDispatcherAwareDelegator::class,
                ],
            ],
            'invokables' => [
                Middleware\PreHandleMiddleware::class  => Middleware\PreHandleMiddleware::class,
                Middleware\PostHandleMiddleware::class => Middleware\PostHandleMiddleware::class,
            ],
        ];
    }

    /**
     * @return array<string, mixed>
     */
    public function getPipeline(): array
    {
        return [
            'pre_handle'  => [
                'middleware' => Middleware\PreHandleMiddleware::class,
                'priority'   => 100,
            ],
            'post_handle' => [
                'middleware' => Middleware\PostHandleMiddleware::class,
                'priority'   => -100,
            ],
        ];
    }
}
```

## Methods

### `__invoke(): array<string, mixed>`

Returns the complete configuration array for the package.

**Returns:** Configuration array with two keys:

- `dependencies` - Service manager configuration
- `BusProvider::class` - Command bus pipeline configuration

**Example:**

```php
$config = (new ConfigProvider())();
```

### `getDependencies(): array<string, mixed>`

Returns the dependency injection configuration.

**Returns:** Array with two keys:

- `invokables` - Services that can be instantiated directly
- `delegators` - Delegator factories for service decoration

**Configuration Structure:**

```php
[
    'delegators' => [
        // Injects event dispatcher into middleware
        Middleware\PreHandleMiddleware::class => [
            EventDispatcherAwareDelegator::class,
        ],
        Middleware\PostHandleMiddleware::class => [
            EventDispatcherAwareDelegator::class,
        ],
    ],
    'invokables' => [
        // Simple instantiation - no dependencies
        Middleware\PreHandleMiddleware::class => Middleware\PreHandleMiddleware::class,
        Middleware\PostHandleMiddleware::class => Middleware\PostHandleMiddleware::class,
    ],
]
```

### `getPipeline(): array<string, mixed>`

Returns the command bus middleware pipeline configuration.

**Returns:** Array of middleware configurations keyed by name

**Configuration Structure:**

```php
[
    'pre_handle' => [
        'middleware' => Middleware\PreHandleMiddleware::class,
        'priority' => 100,  // High priority - runs early
    ],
    'post_handle' => [
        'middleware' => Middleware\PostHandleMiddleware::class,
        'priority' => -100,  // Low priority - runs late
    ],
]
```

## Registration

### Automatic Registration

With Laminas Component Installer, the package automatically registers itself:

```json
// composer.json
{
    "extra": {
        "laminas": {
            "config-provider": "Webware\\CommandBus\\Event\\ConfigProvider"
        }
    }
}
```

When you install the package, the installer adds it to your `config/config.php`:

```php
// config/config.php
$aggregator = new ConfigAggregator([
    \Webware\CommandBus\Event\ConfigProvider::class,
    // ... other config providers
]);
```

### Manual Registration

If you don't use the component installer, manually add the ConfigProvider:

```php
// config/config.php
use Laminas\ConfigAggregator\ConfigAggregator;
use Webware\CommandBus\Event\ConfigProvider;

$aggregator = new ConfigAggregator([
    // ... other providers
    ConfigProvider::class,
    // ... more providers
]);

return $aggregator->getMergedConfig();
```

```php
[
    'dependencies' => [
        'invokables' => [
            'Webware\CommandBus\Event\Middleware\PreHandleMiddleware' =>
                'Webware\CommandBus\Event\Middleware\PreHandleMiddleware',
            'Webware\CommandBus\Event\Middleware\PostHandleMiddleware' =>
```

## Middleware Priority System

The priority system determines the order of middleware execution:

- **Higher numbers** = **Earlier execution**
- **Lower numbers** = **Later execution**

### Default Priorities

```text
Priority 100:  PreHandleMiddleware   (runs early, before handler)
Priority 0:    Default middleware    (runs around handler)
Priority -100: PostHandleMiddleware  (runs late, after handler)
```

### Custom Priority

You can adjust priorities in your local configuration:

```php
// config/autoload/command-bus.local.php

use Webware\CommandBus\ConfigProvider as BusProvider;
use Webware\CommandBus\Event\Middleware\PreHandleMiddleware;

return [
    BusProvider::class => [
        BusProvider::MIDDLEWARE_PIPELINE_KEY => [
            'pre_handle' => [
                'middleware' => PreHandleMiddleware::class,
                'priority' => 200, // Run even earlier
            ],
        ],
    ],
];
```

## Delegator Factories

The `EventDispatcherAwareDelegator` injects the event dispatcher into middleware:

```php
// Simplified flow
$middleware = new PreHandleMiddleware();  // Invokable creates instance

// Delegator decorates it
$eventDispatcher = $container->get(EventDispatcherInterface::class);
$middleware->setEventDispatcher($eventDispatcher);

return $middleware;  // Returns decorated middleware
```

This allows middleware to dispatch events without directly depending on the event dispatcher in the constructor.

## Dependency Injection Types

### Invokables

Used for services with no constructor dependencies:

```php
'invokables' => [
    PreHandleMiddleware::class => PreHandleMiddleware::class,
]

// Equivalent to:
new PreHandleMiddleware();
```

### Delegators

Used to decorate services after creation:

```php
'delegators' => [
    PreHandleMiddleware::class => [
        EventDispatcherAwareDelegator::class,
    ],
]

// Calls the delegator with the created service
$delegator->__invoke($container, $name, $callback);
```

## Customizing Configuration

### Adding Custom Middleware

Add your own middleware to the pipeline:

```php
// config/autoload/custom-middleware.global.php

use App\Middleware\MyCustomMiddleware;
use Webware\CommandBus\ConfigProvider as BusProvider;

return [
    'dependencies' => [
        'factories' => [
            MyCustomMiddleware::class => MyCustomMiddlewareFactory::class,
        ],
    ],
    BusProvider::class => [
        BusProvider::MIDDLEWARE_PIPELINE_KEY => [
            'my_custom' => [
                'middleware' => MyCustomMiddleware::class,
                'priority' => 50, // Between pre and post
            ],
        ],
    ],
];
```

### Overriding Default Priority

Override the default middleware priorities:

```php
// config/autoload/command-bus.local.php

use Webware\CommandBus\ConfigProvider as BusProvider;
use Webware\CommandBus\Event\Middleware;

return [
    BusProvider::class => [
        BusProvider::MIDDLEWARE_PIPELINE_KEY => [
            'pre_handle' => [
                'middleware' => Middleware\PreHandleMiddleware::class,
                'priority' => 150, // Custom priority
            ],
            'post_handle' => [
                'middleware' => Middleware\PostHandleMiddleware::class,
                'priority' => -50, // Custom priority
            ],
        ],
    ],
];
```

### Disabling Middleware

Remove middleware by unsetting it in local config:

```php
// config/autoload/command-bus.local.php

use Webware\CommandBus\ConfigProvider as BusProvider;

return [
    BusProvider::class => [
        BusProvider::MIDDLEWARE_PIPELINE_KEY => [
            'post_handle' => null, // Disable PostHandleMiddleware
        ],
    ],
];
```

## Testing Configuration

### Unit Testing

Test the ConfigProvider in isolation:

```php
<?php

declare(strict_types=1);

namespace WebwareTest\CommandBus\Event;

use PHPUnit\Framework\TestCase;
use Webware\CommandBus\Event\ConfigProvider;

final class ConfigProviderTest extends TestCase
{
    private ConfigProvider $provider;

    protected function setUp(): void
    {
        $this->provider = new ConfigProvider();
    }

    public function testInvoke(): void
    {
        $config = ($this->provider)();

        $this->assertIsArray($config);
        $this->assertArrayHasKey('dependencies', $config);
    }

    public function testGetDependencies(): void
    {
        $dependencies = $this->provider->getDependencies();

        $this->assertArrayHasKey('invokables', $dependencies);
        $this->assertArrayHasKey('delegators', $dependencies);
    }

    public function testGetPipeline(): void
    {
        $pipeline = $this->provider->getPipeline();

        $this->assertArrayHasKey('pre_handle', $pipeline);
        $this->assertArrayHasKey('post_handle', $pipeline);

        $this->assertSame(100, $pipeline['pre_handle']['priority']);
        $this->assertSame(-100, $pipeline['post_handle']['priority']);
    }
}
```

### Integration Testing

Test the full configuration with a container:

```php
<?php

namespace WebwareIntegrationTest\CommandBus\Event;

use PHPUnit\Framework\TestCase;
use Laminas\ServiceManager\ServiceManager;

final class ConfigProviderIntegrationTest extends TestCase
{
    public function testMiddlewareCanBeRetrievedFromContainer(): void
    {
        $config = (new ConfigProvider())();
        $container = new ServiceManager($config['dependencies']);

        $preMiddleware = $container->get(PreHandleMiddleware::class);
        $postMiddleware = $container->get(PostHandleMiddleware::class);

        $this->assertInstanceOf(PreHandleMiddleware::class, $preMiddleware);
        $this->assertInstanceOf(PostHandleMiddleware::class, $postMiddleware);
    }
}
```
